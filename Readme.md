Функционал:
    1. Карточки животных. Фотографии и данные.
    2. Фильтрация. Можно выбрать собак, кошек или показать всех
    3. Избранное. Пользователь нажимает на сердечко и животное сохраняется в избранное
    4. Подробная инфа. При нажатии на карточку открывается окно с описанием животного
    5. Добавление животных. Через специальную форму можно самостоятельно добавить нового питомца
